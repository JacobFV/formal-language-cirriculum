What it generates

Which service discipline governs these interaction traces?

A server answers requests in *some* order. The candidate protocols are given parametrically — sort by arrival / priority / name, ascending or descending — so their names are opaque labels and only the traces identify the rule. The generator keeps a world only when exactly one candidate reproduces every trace, so "consistent with the evidence" is a fact.
