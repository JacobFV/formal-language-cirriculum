#36 question_answering

interrogative form -> reasoning operation

level 36section iiiproof_searchquantification
4.5 answers per episode
0.23 uniform-guess floor
0.125 constant-guess floor
100 samples below

What it generates

who / what / where / when / how-many over an explicit event world.

Each interrogative is a different reasoning operation over the same facts. The generator enumerates the questions whose answer is *unique* and samples among them, and for counting questions samples uniformly over the achievable counts so that "one" is not the default reply.

reasoning_depth3
