What it generates

Reason about the goals themselves: which one has to go?

Conflict is not declared, it is *derived* — two goals conflict when they demand different values of the same state variable. Exactly one such pair exists, and the goal to abandon is its lower-priority member, so both the conflict and the resolution have to be computed.
