What it generates

Four candidate models, one dataset, one held-out prediction.

Exactly one model reproduces every observation, and all four disagree at the query point — so the answer vocabulary *is* the set of rival predictions and picking the right number is exactly picking the right theory. Model selection and prediction are graded as one act, which is what makes this induction rather than curve-fitting.
