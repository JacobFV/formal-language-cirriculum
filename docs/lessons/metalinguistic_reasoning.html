questions about a grammar: grammaticality and ambiguity, by parsing

100 samples below

What it generates

A question *about* a grammar: how many parses does this string have?

The grammar is invented per episode and is genuinely ambiguous (``S -> S S`` and friends), so the answer is a count of derivation trees — computed by CYK, never annotated. 0 means the string is ungrammatical, 1 unambiguous, ≥2 ambiguous, and the target count is drawn uniformly so no constant is right more than a quarter of the time.
