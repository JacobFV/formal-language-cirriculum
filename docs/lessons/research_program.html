What it generates

Pick the next research action from a partially resolved question graph.

An action is available only if everything it depends on is already resolved, and it is worth taking in proportion to how much of the remaining programme it unblocks. Both conditions are structural, so "what should I work on next" reduces to reachability plus a count.
