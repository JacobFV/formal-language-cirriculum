What it generates

Same problem, four encodings, very different search costs.

The constraint network is fixed; what varies is the order the variables are instantiated in. Each candidate order is run through the stated procedure (chronological backtracking, ascending values, first solution) and the node counts are compared exactly, so the answer is a property of the search tree rather than of how the ordering looks.
