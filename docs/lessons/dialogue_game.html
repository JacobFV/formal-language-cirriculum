What it generates

A two-party clarification dialogue, run to agreement, then asked about.

``a`` wants one object and describes it one attribute at a time; ``b`` reports how many objects still match and the pair keeps going until the description is unique. Crucially ``a`` opens with a *wrong* attribute value and repairs it mid-dialogue, so the referent is fixed by the dialogue **state** rather than by the bag of words in the transcript: an agent that intersects every mentioned attribute lands on a different object, or on none.
