What it generates

Merge partially conflicting theories into the consensus they imply.

Three researchers publish partial assignments over the same variables and disagree. The merge rule is stated: majority among those who took a stand, ties broken by seniority. The queried variable always carries a genuine conflict, so the consensus value has to be computed rather than copied.
