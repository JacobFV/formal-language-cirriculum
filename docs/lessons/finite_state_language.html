#6 finite_state_language

stateful syntax / automata induction

level 6section i
2.0 answers per episode
0.5 uniform-guess floor
0.555 constant-guess floor
100 samples below

What it generates

Accept/reject strings of a hidden regular language (parity of a symbol).

Difficulty axes

axislevel
grammar_complexity2
reasoning_depth2

The same episode, in each language

english

You are shown these examples: bbbaa → yes, aaba → yes, aabb → no and abbbab → no.
Is the string bb in the language?

Answer with exactly one of: yes | no
Reply with the answer only.

spanish

Se muestran estos ejemplos: bbbaa → sí, aaba → sí, aabb → no y abbbab → no.
¿La cadena bb pertenece al lenguaje?

Responde exactamente con una de estas opciones: sí | no
Responde sólo con la respuesta.

chinese

示例如下：bbbaa → 是；aaba → 是；aabb → 否；abbbab → 否。
字符串bb属于该语言吗？

请从以下选项中选出恰好一个作答：是 | 否
只回答答案本身。
