#6 finite_state_language

stateful syntax / automata induction

level 6section i
2.0 answers per episode
0.5 uniform-guess floor
0.555 constant-guess floor
100 samples below

What it generates

Accept/reject strings of a hidden regular language (parity of a symbol).

Difficulty axes

axislevel
grammar_complexity2
reasoning_depth2

The same episode, in each language

english

You are shown these examples: bbbaa → yes; aaba → yes; aabb → no; abbbab → no.
Is string bb accepted?

Answer with exactly one of: yes | no
Reply with the answer only.

spanish

Se muestran estos ejemplos: bbbaa → sí; aaba → sí; aabb → no; abbbab → no.
¿String: bb es aceptado?

Responde exactamente con una de estas opciones: sí | no
Responde solo con la respuesta.

chinese

示例如下：bbbaa → 是；aaba → 是；aabb → 否；abbbab → 否。
string：bb是已接受吗？

请从以下选项中选择一个作答：是 | 否
只回答答案本身。

turkish

Size şu örnekler gösteriliyor: bbbaa → evet; aaba → evet; aabb → hayır; abbbab → hayır.
String: bb accepted mi?

Tam olarak şu seçeneklerden biriyle yanıtla: evet | hayır
Sadece yanıtı yaz.

swahili

Unaonyeshwa mifano hii: bbbaa → ndiyo; aaba → ndiyo; aabb → hapana; abbbab → hapana.
String: bb ni accepted je?

Jibu kwa kuchagua moja tu kati ya haya: ndiyo | hapana
Andika jibu pekee.
