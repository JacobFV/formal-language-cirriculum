What it generates

A hidden law runs a world; the trajectory is shown; predict the next state.

Half the episodes are an elementary cellular automaton on a ring, half an affine recurrence in a modular arithmetic system. In both, the episode is *rejected* unless every rule consistent with the displayed trajectory agrees on the next state — so the answer is entailed by what the learner sees, not merely by what the generator knows. The previous state is always offered as a distractor, so "predict no change" is available and always wrong.
