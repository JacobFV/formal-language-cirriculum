What it generates

Compile a high-level program to primitives, then run it.

Macros are defined in terms of primitives *and of each other*, and a ``times`` construct repeats a token, so the compiled instruction stream is several times longer than what is written. Only the final value is graded, and the distractors are the values produced by the three natural failures: not expanding macros, treating ``times n`` as ``times 1``, and expanding only the outermost macro layer.
