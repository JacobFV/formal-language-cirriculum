What it generates

A good conjecture is true *and* not already known.

A concrete structure (a full truth assignment) is generated together with a premise set it satisfies. Exactly one of four candidate claims is both true in the structure and *underdetermined* by the premises — the others are either false in the structure or already entailed, and both conditions are checked by enumerating every valuation.
