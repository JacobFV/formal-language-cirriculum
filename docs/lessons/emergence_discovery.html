What it generates

Which coarse variable has a life of its own?

A micro trajectory is shown together with four candidate macrostates. One of them is *predictively closed* on that trajectory — every time it takes a value it goes to the same next value, so it obeys a law at its own level — and the other three are not: each revisits a value and then does something different, which is exactly the evidence that they leak information to the micro scale. Every candidate is forced to revisit a value at least once, so closure is never true vacuously, and the check is run on the *shown* trajectory, so the answer is a fact about the observation.
