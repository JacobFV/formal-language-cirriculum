What it generates

Reasoning costs something; spend the budget where it pays.

Every operator states a cost, a success probability and a payoff, and the budget rules some of them out — including, most of the time, the one with the highest expected value overall, so "pick the best operator" and "pick the best affordable operator" come apart. Expected values are compared in scaled integers, so there are no floating-point ties.
