What it generates

Which index to build over a symbolic store, given the retrieval workload.

An unindexed lookup scans; an index makes its own fields cheap and everything else unchanged; a composite index costs more to build but covers two fields. Exactly one design minimizes the total, and it is not always the one with the smallest build cost or the widest coverage.
