What it generates

Assertion, correction, retraction and uncertainty are different operations.

All four arrive as utterances about a knowledge base and only two of them overwrite it: a retraction takes a slot back to ``unknown`` and a hedge leaves it exactly as it was. The query sometimes names an untouched slot, so "return whatever the utterance mentioned" is wrong a third of the time.
