#18 event_semantics

participants and times of named events

level 27section ii
4.0 answers per episode
0.293 uniform-guess floor
0.175 constant-guess floor
100 samples below

What it generates

Neo-Davidsonian events: each has an id, a predicate, two participants and a time. Queries ask either for a participant of a named event or for the temporal extremum. Times are a shuffled sample, so the event id says nothing about when it happened, and the event list order says nothing either.
