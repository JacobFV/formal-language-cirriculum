What it generates

Which intermediate proposition, taken as a lemma, buys the most?

Proof cost is tree size, so a proposition that is re-derived inside several branches is worth far more as a lemma than one used once. The generator computes the goal's minimal derivation cost with and without each of four candidate lemmas and keeps the episode only when one candidate's saving is strictly the largest.
