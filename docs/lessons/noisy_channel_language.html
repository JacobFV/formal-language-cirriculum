#54 noisy_channel_language

error correction from redundancy

level 54section ivfinite_state_inductionabstraction
5.0 answers per episode
0.2 uniform-guess floor
0.2 constant-guess floor
100 samples below

What it generates

A codebook with slack, a message damaged in transit, one recoverable reading.

The codebook is drawn with pairwise Hamming distance at least three, so a single substitution, deletion or transposition leaves the sent word strictly nearest to what arrived. That is *checked*, not assumed: the generator scores the corrupted string against every codeword and rejects any episode where the minimum is tied or lands on the wrong word, so a decoder that reasons about the redundancy is exactly right and a decoder that pattern-matches is not.
