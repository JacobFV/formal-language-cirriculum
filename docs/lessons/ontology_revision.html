What it generates

An established taxonomy meets one anomalous entity; which revision fixes it?

The anomaly either *lacks* a property its declared type inherits or *has* one the type does not license. Four revisions (exception, extra attribute, split, merge, generalization, reassignment) are presented; each is applied by :func:`_apply_op` and re-checked with :func:`_consistent`, and exactly one of the four presented candidates restores consistency.
