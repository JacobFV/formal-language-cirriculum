What it generates

Ordering is the whole lesson: same material, four sequences.

A lesson is learned only if its prerequisites are already learned, and a lesson presented too early is simply lost. So the four orderings differ in how many of the same lessons actually land — computed by simulating each sequence against the student's starting knowledge, with a unique maximum required.
