Which new predicate compresses the corpus most?

A predicate ``P(X,Y) := r1(X,Y) & r2(X,Y)`` costs nine symbols to define and saves three for every pair of facts it folds up, so it pays only if it recurs. Description length is counted exactly, before and after rewriting; the winner is required to be the unique minimum and to beat writing the corpus out flat.
