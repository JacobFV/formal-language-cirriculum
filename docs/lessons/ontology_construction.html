What it generates

Which of four type hierarchies explains every observation?

Observations are an entity's *complete* property set. A hierarchy is consistent iff, for every entity, the properties inherited along its type's ``sub`` chain are exactly the ones observed — so consistency is set equality and the label is computed, not annotated. Distractors are perturbations of the true hierarchy that are each verified to be inconsistent.
