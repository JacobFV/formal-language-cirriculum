#13 quantification

generalized quantifiers

level 12section ii
2.0 answers per episode
0.5 uniform-guess floor
0.525 constant-guess floor
100 samples below

What it generates

The truth value is chosen FIRST and the scene built to match it.

Sampling a scene and reading off the truth value makes most quantified statements false, so a constant "no" scores ~0.73 and the lesson measures nothing. The verifier caught exactly this.
