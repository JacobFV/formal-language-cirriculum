supplementary set_operations

boolean algebra over property sets

level 26section supplementary
4.0 answers per episode
0.25 uniform-guess floor
0.27 constant-guess floor
100 samples below

What it generates

Conjunction, disjunction and negation over property sets. Formulas are sampled and then *rejected* unless they denote exactly one object, so the description is a definite one and the answer is unique.
