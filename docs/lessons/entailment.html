What it generates

Three-way natural-language inference over a tiny closed world: a universal rule, some ground facts, a uniqueness axiom for colour, and one entity about which *nothing* is stated. The label is chosen first and the premises are then built to realize it, with the roles assigned to shuffled entity names so no name predicts the label.
