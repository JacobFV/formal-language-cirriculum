#28 lexicon_induction

acquiring a new language in-episode

level 14section iii
4.0 answers per episode
0.25 uniform-guess floor
0.38 constant-guess floor
100 samples below

What it generates

Every episode invents a NEW language. Support examples ground novel words; the query uses them compositionally. Nothing carries over between episodes, so a learner that memorizes a vocabulary learns nothing here.

Difficulty axes

axislevel
compositional_depth2
lexical_novelty3
reasoning_depth2

The same episode, in each language

english

You are told: skt says yellow, psp says green and zss says orange.
In the scene: o0 is a green sphere at (4, 2); o1 is a yellow disc at (4, 8); o2 is an orange disc at (2, 4); o3 is a red rod at (1, 5).
Find the skt object.

Answer with exactly one of: o0 | o1 | o2 | o3
Reply with the answer only.
