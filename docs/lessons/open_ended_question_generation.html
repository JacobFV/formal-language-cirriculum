What it generates

Which question is worth asking: the one that eliminates the most hypotheses.

Every live hypothesis states what it predicts for every candidate question, so a question's worst-case yield is the number of hypotheses ruled out whichever way the answer comes back. This is expected-information-gain reduced to counting, which is what makes "the agent decides what to ask" scoreable.
