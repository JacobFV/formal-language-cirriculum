100 samples below

What it generates

An arbitrary signal→action pairing, recoverable only from the episode.

The convention is a fresh random bijection each episode, so there is nothing to memorize across episodes; and the queried signal is never demonstrated successfully, so the answer is not a lookup. It follows from the convention being *shared and exclusive*: three signals are pinned by successful trials, the failed trials rule out more, and one action is left for the fourth signal.
