What it generates

Four invented languages, one task set: which says it in fewest symbols?

Each language is a lexicon of numerals plus one compositional rule (juxtaposition sums values), so the cost of expressing a meaning is an exact minimum-coin computation and the cost of the task set is a sum. The generator rejects any world without a strict argmin, so "design" here is a decidable comparison rather than a matter of taste.
