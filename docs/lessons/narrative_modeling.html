What it generates

Which event was the pivot — the one whose removal changes the ending?

Events fire only when their precondition already holds, so the story is a chain of enablements with redundant links in most places and exactly one bottleneck. Pivotality is defined operationally and verified by deleting each event in turn and re-running the whole narrative; worlds with zero or several pivots are discarded.
