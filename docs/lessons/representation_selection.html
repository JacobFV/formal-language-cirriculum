What it generates

One latent chain, four encodings, one query: which encoding costs least?

``graph`` is a shuffled edge list (each edge is found by scanning), ``sequence`` an ordered list (scan to the item, then walk), ``set`` an unordered bag with O(1) membership and no successor at all, ``table`` keyed rows that must be indexed first. The four coefficients of the cost model are resampled every episode and shown in the observation, so no encoding is a standing answer: the four costs have to be computed.
