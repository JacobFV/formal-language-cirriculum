What it generates

Attribute a failure to the stage that caused it.

The pipeline's stages each declare a deterministic transformation and the trace records what each stage actually emitted. Exactly one stage deviates from its own specification; every later stage then processes the *corrupted* value correctly, so the whole tail of the trace is wrong and only the first deviation identifies the culprit. Attribution therefore requires replaying the pipeline, not spotting an odd number.
