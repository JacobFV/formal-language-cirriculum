What it generates

Ask, or act? and if asking, ask about *what*.

The instruction names one attribute value. If it already denotes uniquely the right move is to act; otherwise exactly one other attribute separates all the candidates, and every other question would come back ambiguous — so the value of each possible question is computed, not guessed.
