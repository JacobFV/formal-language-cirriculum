What it generates

Which invented DSL makes the recurring computations shortest?

Every candidate offers two macros over the same primitives; writing a task is a shortest-segmentation problem, solved by dynamic programming. The tasks are built from repeated motifs, so a DSL that names the right motif wins — and which one that is cannot be read off the surface, only computed.
