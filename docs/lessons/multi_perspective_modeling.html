#133 multi_perspective_modeling

what an agent believes, given what it was there to see

level 133section xiibelief_modelingtemporal_reasoningmulti_agent_coordination
4.0 answers per episode
0.25 uniform-guess floor
0.285 constant-guess floor
100 samples below

What it generates

Where does *this* agent think the ball is?

Agents come and go while the ball is moved; an agent's belief is whatever it last saw, which is the truth only if it was in the room for the final move. Half the episodes are built so the queried agent's belief and the world disagree, so an agent that reports the true location is right at chance.
