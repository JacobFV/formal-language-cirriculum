What it generates

Microscopic transport, macroscopic question.

The micro rule (a site permutation — transport that moves stuff without creating or destroying it) is never named: it has to be read off the shown trajectory, which is possible because site contents are distinct. The question is then asked at the coarse scale, several steps past the end of the trajectory: the mass of the left half. Getting it requires both scales — identify the micro dynamics, run them forward, then coarse-grain — and the distractors are the coarse variable's values at *other* times, so the macro-level answer alone is not guessable from the trajectory.
